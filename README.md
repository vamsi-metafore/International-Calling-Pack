# International-Calling-Pack

**International Calling Pack — Cheaper Calls to Selected Countries - Jira Project: INTCP**

## Features

- Pack browsing
- purchase journey
- real-time rating
- balance visibility
- renewal notification
- whitelabel brand support

## Overview

International Calling Pack for Telefónica Germany (O2) lets customers buy affordable calling minutes from Germany to selected destinations, track usage, and renew packs with clear balance and rating visibility.

## Supported countries

Calls from Germany to these destinations (Telefónica Germany / O2 International Pack):

- Turkey
- India
- Poland
- Romania
- Ukraine
- Russia
- USA
- Canada
